# DOGAGA 権利・データ取扱方針（初期案）

更新日: 2026-07-17

> この文書はプロダクト設計のための初期方針であり、法律相談ではない。一般公開、課金、外部API連携、素材配布、作品公開機能を始める前に、専門家による利用規約・プライバシーポリシー・ライセンス確認を行う。

## 1. 基本原則

1. ユーザーの素材は、ユーザーのものとする。
2. 動画・音声・画像の本体は、可能な限り端末内で処理する。
3. サーバー送信が必要な機能は、送信前に目的、送信先、保存期間を明示する。
4. 外部AI処理を、編集に必須の前提にしない。
5. DOGAGAは、素材を利用する権利や投稿先での公開権をユーザーへ付与しない。
6. 権利未確認の楽曲、映像、画像、歌詞、フォントをDOGAGA自身が安易に配布しない。
7. 公開ホスティング機能を持たない「編集して書き出す道具」から始め、権利侵害コンテンツの保管・配信リスクを小さくする。

## 2. ユーザー素材に関する原則

利用規約では、ユーザーに少なくとも次を確認してもらう必要がある。

- アップロードまたは読み込む動画、音声、画像、歌詞、フォント等について、編集・複製・書き出しに必要な権利を持っていること
- 被写体や音声に含まれる人物について、必要な肖像、プライバシー、パブリシティ、出演等の許諾を得ていること
- 第三者の商標、ロゴ、キャラクター、アートワーク等を無断利用しないこと
- 書き出した作品をYouTube、Spotifyその他のサービスへ投稿する場合、投稿先の規約と必要な権利を自ら確認すること
- DOGAGAの編集機能を使っただけでは、権利処理済みにはならないこと

## 3. 音楽・歌詞で特に注意する点

### 3.1 楽曲には複数の権利がある

市販音源には、作詞・作曲に関する著作権だけでなく、実演家やレコード製作者の著作隣接権が関係する。動画投稿サービス側が著作権管理団体と契約していても、市販音源の利用、営利利用、編曲、替歌、訳詞などは別の確認が必要になる場合がある。

DOGAGAは、投稿可否を自動的に保証しない。書き出し時に「素材の権利確認」チェックを表示することは検討できるが、法的判定機能として扱わない。

### 3.2 歌詞は自由なデータではない

歌詞本文も著作物である。したがって、初期版では次の方針とする。

- DOGAGA側から商用曲の歌詞を検索・取得・配布しない
- ユーザーが自分で用意した歌詞を入力する
- 入力された歌詞を学習データへ転用しない
- 外部字幕／翻訳APIへ送る場合は明示的な同意を得る
- 自動翻訳、替歌、表記改変は、権利上の確認が必要になり得ることを案内する

### 3.3 YouTube向け

YouTubeでは、投稿動画がContent IDで照合され、権利者の設定によって収益化、視聴制限、ブロック等の対象になる可能性がある。YouTubeが一部の権利処理を行っていても、ユーザー自身が必要な権利を持つ責任は残る。

DOGAGA内でYouTubeへ直接投稿する機能は、MVPには入れない。まずはファイル書き出しまでとし、投稿先のチェック画面で権利注意を表示する。

### 3.4 Spotify Canvas向け

Spotify Canvasは公式ガイドライン上、次の要件がある。

- 3〜8秒
- 9:16
- 縦720〜1080px
- MP4またはJPG
- 激しい点滅や過度に細かいカットを避ける
- Spotify外部への誘導や過度な宣伝を避ける
- 使用するコンテンツについて必要な権利を持つ

DOGAGAのCanvasプリセットでは、時間、比率、解像度、セーフエリア、点滅、過度な宣伝文言を可能な範囲で警告する。ただし、Spotifyによる受理や法的適合を保証しない。

## 4. 素材ライブラリの方針

### MVP

- ユーザー持ち込み素材のみ
- DOGAGA同梱素材は、自作またはライセンスを明確に確認した最小限のサンプルだけ
- 市販楽曲や「著作権フリー」とだけ書かれた出所不明素材は扱わない

### 将来

素材ライブラリを追加する場合、各素材に次を記録する。

- 権利者／配布元
- ライセンス名と原文URL
- 商用利用可否
- 改変可否
- クレジット要否
- 再配布可否
- AI学習由来かどうか
- 取得日とライセンス版

## 5. フォントの取扱い

- 使用可能なフォントは、ライセンスを台帳化する
- SIL Open Font License等、映像への使用が許されるライセンスを優先する
- ユーザーがアップロードしたフォントは、端末内利用を基本とする
- ユーザーフォントをサーバー保存、テンプレート共有、再配布しない
- 書き出し動画へ文字が画像として焼き込まれる場合と、フォントファイルの配布は別問題として扱う

## 6. OSS・コーデックのライセンス

### FFmpeg / ffmpeg.wasm

FFmpegは基本的にLGPL 2.1以降だが、構成や有効化した部品によってGPLが適用される。導入時に次を行う。

- 実際に使用するビルドのライセンスを確認する
- GPL部品を有効にしたビルドを意図せず採用しない
- 著作権表示、ライセンス文、ソース提供等の義務を確認する
- 依存ライブラリとビルドオプションをThird-Party Noticesへ記録する

### コーデック

WebCodecsはブラウザ実装のコーデックへJavaScriptからアクセスするAPIであり、特定コーデックを保証しない。H.264 / AAC等の採用時は、ブラウザ対応だけでなく、配布形態、商用利用、特許ライセンスの確認を別途行う。

MVPでは、主要ブラウザが提供する機能を利用し、独自にコーデックを同梱する範囲を最小化する。

## 7. データ分類

| 区分 | 例 | 初期方針 |
|---|---|---|
| 元素材 | 動画、音声、画像、フォント | 原則端末内。明示操作なしに送信しない |
| 編集データ | タイムライン、歌詞、字幕、効果設定 | 端末内保存。任意でプロジェクトファイル出力 |
| 作業キャッシュ | プロキシ、波形、サムネイル | OPFS等へ保存。ユーザーが削除可能 |
| 書き出し | 完成MP4等 | ユーザー指定先へ保存 |
| アカウント情報 | メール、認証ID | アカウント機能導入時のみ最小限取得 |
| 利用ログ | 画面遷移、エラー、性能情報 | 内容物やファイル名を避け、必要最小限 |
| AI処理データ | 音声、歌詞、字幕 | オプトイン。送信先と保持条件を表示 |
| 決済情報 | カード情報 | DOGAGAで保持せず決済事業者へ委託 |

## 8. ローカルファースト設計

### 8.1 端末内に置くもの

- 元動画、元音声、画像
- プロジェクトJSON
- 波形、サムネイル、プロキシ
- Undo履歴の必要部分
- 書き出し途中の一時データ

候補技術:

- File API / File System Access API
- OPFS
- IndexedDB
- Web Workers

OPFSは高性能なブラウザ内ストレージとして有用だが、サイトデータの消去で失われ、容量制限もある。したがって、プロジェクトの唯一の保存先にはしない。

### 8.2 サーバーへ送る可能性があるもの

MVPでは基本的に送らない。将来、次の機能を追加するときのみ検討する。

- クラウドバックアップ
- 共同編集
- 外部AIによる文字起こし、翻訳、背景除去
- サーバー側書き出し
- ユーザーサポート用の任意診断データ

各機能では、処理開始前に次を表示する。

- 送信されるデータ
- 処理事業者
- 国または地域
- 保存期間
- 学習利用の有無
- 削除方法
- ローカル処理へ戻る選択肢の有無

## 9. 保存期間の初期案

クラウド機能を導入する場合の仮案。

- 一時アップロード素材: 処理完了後24時間以内に自動削除
- 書き出し一時ファイル: ダウンロード後または24時間以内に削除
- クラウドプロジェクト: ユーザーが削除するまで。退会後30日以内に削除
- バックアップ: 本体削除後、最大30日で循環削除
- セキュリティログ: 90日〜1年を目的別に決定
- 分析ログ: 個人識別性を下げ、必要最小限の期間

実際の期間は、利用目的、委託先、障害対応、法令上の必要性を確認して確定する。

## 10. セキュリティ最低条件

- HTTPS必須
- 認証導入時は安全な外部認証または十分に検証された仕組みを使う
- ユーザーデータをユーザーIDごとに分離する
- 保存データを暗号化する
- 署名付き短時間URLを利用する
- 運営者の素材アクセスを原則禁止し、必要時は記録する
- ログへ歌詞本文、ファイル名、素材URLを不用意に出さない
- ファイル形式とサイズを検証する
- アップロードファイルを実行しない
- 外部依存関係の脆弱性監視を行う
- データ削除機能と障害／漏えい時の対応手順を用意する

個人情報保護委員会は、クラウドサービス提供事業者にも個人情報取扱事業者としての安全管理が問題となり得ること、一定の漏えい等では報告と本人通知が必要になることを示している。一般公開前にインシデント対応表を作成する。

## 11. プライバシーUI

最低限、画面上で次を区別する。

- 「この端末内で処理」
- 「DOGAGAのサーバーへ送信」
- 「外部サービスへ送信」

外部AIボタンには、初回だけでなく処理実行時にも短い説明を出す。利用規約だけに埋め込まない。

## 12. 一般公開前の必須成果物

- 利用規約
- プライバシーポリシー
- 特定商取引法表記（課金する場合）
- Cookie／アクセス解析の説明
- OSS Third-Party Notices
- 素材・フォントのライセンス台帳
- データフロー図
- データ削除手順
- インシデント対応手順
- 問い合わせ／権利侵害申告窓口
- 未成年者の利用方針
- 外部AI／クラウド委託先一覧
