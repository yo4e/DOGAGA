# DOGAGA プロダクト方針

更新日: 2026-07-17

## 1. 一文でいうと

DOGAGA（どーがが）は、**楽曲を中心に、MV・PV・ショート動画・歌詞動画・Spotify Canvasを、ブラウザで迷わず作るための軽量動画編集アプリ**である。

Premiere Proの縮小版ではなく、Canvaの入りやすさを保ちながら、音楽に必要なタイムライン精度、歌詞同期、ディゾルブ、簡単な映像効果を足す。

## 2. 想定する制作物

優先順位は次のとおり。

1. 楽曲の歌詞動画／リリックビデオ
2. YouTube向けの1曲分のMV（おおむね3〜10分）
3. 15秒〜3分程度の縦型ショート動画、ティザー、PV
4. Spotify Canvas向けの3〜8秒ループ動画
5. 静止画、動画、文字、音楽を組み合わせた簡易ビジュアライザー

長編映画、複雑なマルチカメラ編集、放送向けカラーグレーディング、巨大なプラグイン環境は対象外とする。

## 3. プロダクトの中心

### 3.1 Music-first

一般的な動画編集ソフトは「映像を編集し、必要なら音楽を載せる」。DOGAGAは逆に、**楽曲を置き、その時間軸に映像と文字を並べる**。

最初の画面でユーザーに尋ねるのは「何分の動画か」ではなく、次のような制作目的とする。

- 歌詞動画を作る
- 1曲分のMVを作る
- 短いPVを作る
- Spotify Canvasを作る
- 自由サイズで作る

### 3.2 Text-first

DOGAGAの差別化の中心は、字幕一般ではなく**歌詞と文字演出**である。

必須とする体験:

- 歌詞をプレーンテキストで貼り付ける
- 改行単位でテロップ候補へ分割する
- 再生しながらキーを押して各行の開始時刻を打つ（タップ同期）
- タイムライン上で行ごとに微調整する
- 全体を一括で前後にずらす
- 複数行の表示時間をまとめて調整する
- フォント、縁取り、影、背景、位置をプリセット化する
- 縦書き、横書き、中央、下部などを素早く切り替える
- SRT / VTT / LRCの読み込みと書き出しを段階的に対応する

歌唱音声の自動認識は便利だが、誤認識が多い場合に制作を止める。したがって、MVPでは「AIが当たること」より、**人間が短時間で確実に同期できること**を優先する。

### 3.3 Simple, but not toy-like

操作はCanva程度に入りやすくするが、以下は妥協しない。

- フレームに近い粒度でトリム位置を調整できる
- 波形を見ながら編集できる
- ディゾルブ／フェードの長さを数値またはドラッグで変えられる
- 文字の開始・終了がタイムライン上で明確に見える
- プレビューと書き出し結果の差を小さくする
- Undo / Redoが壊れない

## 4. MVPの範囲

### 必須

- 動画、画像、音声の読み込み
- 16:9 / 9:16 / 1:1のキャンバス
- 1080pまでのプレビューと書き出し
- クリップの配置、移動、トリム、分割、複製、削除
- 2〜3本程度の映像レイヤー
- 音声波形、音量、ミュート、フェードイン／アウト
- カット、クロスディゾルブ、黒／白へのフェード
- テキスト／字幕レイヤー
- 歌詞貼り付け、行分割、タップ同期、一括オフセット
- 基本的な文字装飾（フォント、サイズ、色、縁取り、影、背景、整列）
- 基本補正（明るさ、コントラスト、彩度、色温度の簡易版）
- プリセット効果（モノクロ、グレイン、VHS風、ぼかし、グリッチの軽量版）
- プロジェクト保存／再開
- MP4書き出し

### MVP後すぐに検討

- ビート検出とビートマーカー
- クリップをビートへスナップ
- 歌詞の単語単位ハイライト（カラオケ表示）
- LRC / SRT / VTT / ASS対応の拡張
- ループの継ぎ目プレビュー
- Spotify Canvas専用チェック
- 音声からの字幕生成（明示的な同意を伴うローカル処理または外部API）
- テンプレート

### 当面やらない

- 長編映画向け機能
- 無制限トラック
- 複雑なキーフレーム曲線編集
- After Effects相当の合成
- マルチカメラ
- 高度なカラーグレーディング
- DAW相当の音声編集
- ユーザー作品の公開ホスティング／SNS機能
- 市販楽曲や権利未確認素材を配布する素材ストア

## 5. 代表ワークフロー

### A. 歌詞動画

1. 楽曲を置く
2. 背景動画または静止画を置く
3. 歌詞を貼る
4. 行分割を確認する
5. 再生しながら各行の開始位置をタップする
6. タイムラインまたは字幕一覧で誤差を修正する
7. 文字スタイルを全体へ適用する
8. 必要な行だけアニメーションを変える
9. YouTube 16:9またはショート9:16で書き出す

### B. MV / PV

1. 楽曲を中心トラックへ置く
2. ビートまたは任意の位置へマーカーを打つ
3. 映像素材を並べる
4. カット、ディゾルブ、フェードを選ぶ
5. 色味と簡単な効果を調整する
6. タイトル、クレジット、歌詞を追加する
7. 16:9 / 9:16 / 1:1へ複製またはリサイズする
8. 書き出す

### C. Spotify Canvas

1. 9:16 Canvasプリセットを選ぶ
2. 3〜8秒へ長さを制限する
3. Continuous / Hard Cut / Reboundのループ方式を選ぶ
4. セーフエリアとループ継ぎ目を確認する
5. 点滅・過度な宣伝・範囲外時間などを警告する
6. MP4で書き出す

## 6. UX原則

- 初期画面で専門用語を並べない
- 選択中の要素に必要な操作だけを見せる
- タイムラインと字幕一覧を相互に選択できる
- 数値入力とドラッグ操作の両方を用意する
- 破壊的操作はUndo可能にする
- 自動処理は、結果を人間が直しやすい形式で返す
- エクスポート設定は用途プリセットを先に出し、詳細設定は折りたたむ
- 保存場所と外部送信の有無をユーザーに明示する

## 7. 成功条件

最初の実用判定は、機能数ではなく実制作で測る。

- 1曲分の歌詞動画を、別ソフトへ移動せず完成できる
- 30行程度の歌詞を10分以内に概ね同期できる
- 3〜8秒のSpotify Canvasを迷わず書き出せる
- 10本程度の短い素材から1分PVを作れる
- ブラウザを閉じたあともプロジェクトを再開できる
- 素材がサーバー送信される場合、その理由と保存期間が明示される

## 8. 重要な判断

DOGAGAの第一の競争力は「AI機能の数」ではない。

**楽曲、波形、歌詞、文字、ビート、短い映像効果が、同じ画面で自然につながること**を優先する。AIはこの流れを短縮する場合だけ採用し、サービスの中心には置かない。
