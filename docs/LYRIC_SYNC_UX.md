# DOGAGA 歌詞タップ同期 UX仕様

更新日: 2026-07-17

## 1. 目的

歌詞タップ同期は、DOGAGAの中心機能である。

狙いは自動認識の代替ではない。ユーザーが既に持っている正しい歌詞を、楽曲へ短時間かつ確実に同期できることを目指す。

成功条件:

- 初見でも操作を理解できる
- 30行程度の歌詞を10分以内に概ね同期できる
- ミスしても再生を止めずに戻せる
- 全体のずれと途中以降のずれを簡単に直せる
- タイムラインの細かいドラッグだけに依存しない
- AI、サーバーアップロード、音声認識なしで完成できる

## 2. 前提環境

初期版はデスクトップブラウザを対象とする。

- 広い画面で、波形、歌詞一覧、プレビューを同時表示する
- 物理キーボードを主要入力手段として使う
- マウスまたはトラックパッドで細かな時刻調整を行う
- タッチ操作だけで全機能を成立させることはMVPの要件にしない

この前提により、スマートフォン向けに操作を単純化しすぎず、同期速度と修正精度を優先する。

## 3. 基本思想

### 同期と修正を分ける

最初から完璧な時刻を狙わせない。

1. タップ同期で行頭を粗く取る
2. 全体ずれを補正する
3. 明らかなミスだけ個別修正する
4. 必要なら途中以降をまとめてずらす

### 一行ずつ字幕を作らせない

歌詞全文を先に貼り付け、改行を行として扱う。

### 専用モードにする

通常編集ではSpaceキーを再生／停止に使う。

「タップ同期を開始」すると専用モードへ入り、その間だけSpaceキーを行頭記録に使う。通常操作との衝突を避けるため、画面全体の状態を明確に変える。

### 失敗を怖くしない

- 直前操作をすぐ戻せる
- タップ履歴を保持する
- 同期済み／未同期が明確
- 再実行しても歌詞本文とスタイルを失わない
- 同期結果を確定する前に確認できる

## 5. 歌詞取り込み

### 入力方法

- テキスト貼り付け
- テキストファイル読み込み
- LRC読み込み
- SRT / VTT読み込み

MVPではテキスト貼り付けを最優先にする。

### 行分割

初期動作:

- 改行一つを一行として扱う
- 空行は区切りとして保持するか削除するか選べる
- 連続空白は原文どおり保持する
- 自動で句読点分割しない

補助操作:

- 行を上と結合
- 行を下と結合
- カーソル位置で分割
- 行を複製
- 行を削除
- Undo / Redo

### 原文保護

取り込み直後の歌詞本文をOriginal Lyricsとして保持し、いつでも比較または復元できるようにする。

自動整形は実行前に変更内容を表示する。

## 6. 同期モード開始

ユーザーが「タップ同期を開始」を押すと、次を確認する。

- 対象音声トラック
- 開始する歌詞行
- 再生開始位置
- タップ遅延補正
- 3秒カウントインの有無

推奨初期値:

- 対象: メイン楽曲
- 開始行: 最初の未同期行
- 再生位置: 選択行の直前5秒。未同期なら曲頭
- 遅延補正: 0ms
- カウントイン: あり

開始後、自動的に楽曲を再生する。

## 7. 同期モードのキー操作

### Space

現在時刻を現在行の開始時刻として記録する。

記録後:

- 現在行を同期済みにする
- 次の行へ自動移動する
- 次の行を画面中央付近へスクロールする
- 波形へマーカーを追加する

### Backspace

直前のタップを取り消す。

- 一つ前の行へ戻る
- その行の新しい時刻を削除する
- 再生は続ける

テキスト入力欄にフォーカスがある場合は通常の文字削除を優先し、同期操作を発火しない。

### Enter

再生／停止を切り替える。

Spaceを同期専用へ割り当てるため、同期モード中の再生制御はEnterを使う。

### Esc

同期モードを一時停止する。

- 再生を止める
- 現在行を保持する
- 同期済みデータを保持する
- 「続きから再開」を表示する

### 矢印キー

停止中に使用する。

- 左／右: 再生ヘッドを小さく移動
- Shift + 左／右: より大きく移動
- 上／下: 歌詞行を移動

移動単位は設定可能にする候補がある。

- 1フレーム
- 10ms
- 50ms
- 100ms

MVPではフレーム単位と100ms単位を候補とする。

## 8. タップ遅延補正

人間は聞こえた瞬間より少し遅れてキーを押す。端末、Bluetooth音声、個人差でも遅延が変わる。

同期時刻は次で決める。

```text
記録時刻 = キー入力時の再生時刻 + ユーザー補正値
```

補正値例:

- `0ms`: 補正なし
- `-80ms`: タップより80ms前へ置く
- `-150ms`: タップより150ms前へ置く

### 補正の決め方

初回同期前に、短い試験を用意する候補:

1. 既知のクリック音またはビートを再生する
2. ユーザーが数回タップする
3. 平均遅延を候補として提示する
4. ユーザーが採用または修正する

MVPでは手動設定を先に実装し、自動計測は後回しでもよい。

補正値はプロジェクトだけでなく端末設定として保存できると便利だが、Bluetooth機器変更時は再確認を促す。

## 9. 行の終了時刻

タップ同期では、まず開始時刻だけを記録する。

初期終了時刻:

```text
現在行の終了 = 次の行の開始 - gap
```

`gap`初期値候補:

- 0ms
- 50ms
- 100ms

最終行は次のいずれかを選ぶ。

- 楽曲終端まで
- 指定秒数
- 手動設定

空白区間が長い場合は、前行を自動延長しすぎない上限を設ける候補がある。

## 10. 同期結果の確認

同期終了後、確認モードへ移る。

表示:

- 歌詞一覧
- 波形
- 行頭マーカー
- 現在行の開始／終了
- 未同期行
- 順序異常
- 極端に短い／長い表示時間

自動チェック:

- 時刻が前の行より早い
- 同じ時刻の行が連続する
- 100ms未満の行
- 10秒以上の行
- 楽曲範囲外
- 未同期行

数値は初期候補であり、実制作で調整する。

## 11. 修正操作

### 個別時刻の修正

- 波形上でマーカーをドラッグ
- 開始時刻を数値入力
- 矢印キーで微調整
- 再生ヘッド位置へ設定

### 全体オフセット

全歌詞を同じ量だけ移動する。

例:

- `-120ms`
- `+0.3秒`

プレビューしながら確定できるようにする。

### 選択行以降を移動

途中からずれた場合に使う。

操作:

1. 基準行を選ぶ
2. 「この行以降をずらす」
3. 移動量を入力またはドラッグ
4. プレビュー
5. 確定

DOGAGAの重要差別化機能なので、コンテキストメニューの奥へ隠さない。

### 選択範囲を伸縮

将来候補。

開始と終了は合うが、途中だけ徐々にずれる場合に、選択範囲内の時刻を比率で再配置する。

例:

- 10行目を60.0秒に固定
- 20行目を90.0秒に固定
- 11〜19行目をその間へ比例配置

MVP後の実制作で必要性を確認する。

## 12. 再同期

既存の同期結果がある場合、次を選べる。

- 未同期行だけ続ける
- 選択行から上書きする
- 全行をやり直す
- 新しい同期テイクとして保存する

上書き前に、現在の同期結果を履歴へ残す。

同期テイク比較は将来機能だが、少なくともUndoで戻せるようにする。

## 13. フォーカスと誤操作防止

ブラウザアプリでは、キー操作が入力欄やOSショートカットと衝突しやすい。

原則:

- 入力欄フォーカス中は文字編集を優先する
- 同期モード中は画面枠や背景色を変える
- Space操作が有効な場所を明示する
- ブラウザのページスクロールを発生させない
- ウィンドウが非アクティブになった場合は同期を自動停止する
- 音声出力機器変更時は警告する候補を持つ
- キー長押しによる連続記録を無効にする

## 14. データモデル案

```text
LyricsDocument
├─ sourceText
├─ normalizedText
├─ lines[]
│  ├─ id
│  ├─ text
│  ├─ startTime
│  ├─ endTime
│  ├─ syncStatus
│  ├─ styleId
│  └─ overrides
├─ syncSettings
│  ├─ audioAssetId
│  ├─ latencyOffsetMs
│  ├─ endGapMs
│  └─ lastActiveLineId
└─ syncHistory[]
```

時間値は浮動小数点秒だけで保持せず、内部基準を統一する。

候補:

- 整数マイクロ秒
- 整数ミリ秒
- タイムベース付き整数tick

映像fpsと音声サンプルレートをまたぐため、整数マイクロ秒または明示的なタイムベースを推奨する。

## 15. Undo / Redo単位

次を独立コマンドとして扱う。

- ImportLyrics
- SplitLyricLine
- MergeLyricLines
- SetCaptionTiming
- ClearCaptionTiming
- ShiftAllCaptions
- ShiftCaptionRange
- ApplyCaptionStyle
- RestoreOriginalLyrics

タップ同期中は、各タップを一件ずつ戻せる。

同期終了後は、一回の同期セッション全体をまとめて戻す操作も検討する。

## 16. アクセシビリティ

- 色だけで同期済み／未同期を区別しない
- 現在行をアイコン、太字、位置でも示す
- キーボードだけで開始、同期、停止、修正できる
- ショートカット一覧を常時確認できる
- 文字サイズを拡大しても歌詞一覧が壊れない
- 音声波形だけに情報を依存しない

## 17. 計測項目

実装後に記録する。

- 30行の同期完了時間
- 一行あたりの平均タップ時間
- Backspace使用回数
- 停止／再開回数
- 全体オフセット使用回数
- 範囲オフセット使用回数
- 個別ドラッグ修正回数
- 同期後の平均誤差
- 操作説明を読まずに開始できた割合

操作ログを収集する場合は、歌詞本文や音源内容を送信せず、明示同意を得る。

## 18. MVP完了条件

- テキスト歌詞を貼り付け、行へ分割できる
- 専用同期モードへ入れる
- Spaceで行頭時刻を記録できる
- Backspaceで直前の記録を戻せる
- 停止後に続きから再開できる
- 全体オフセットが使える
- 選択行以降のオフセットが使える
- 波形または数値で個別修正できる
- プロジェクト保存後も同期結果が残る
- SRTまたはLRCへ書き出せる
- 30行を10分以内に概ね同期できる

## 19. 後回しにするもの

- 歌唱音声からの自動歌詞認識
- 単語単位の自動アラインメント
- 多言語翻訳
- ルビの高度な編集
- 複数人による同時編集
- スマートフォンのタップ専用UI
- MIDIパッド等の外部入力機器

まずは、物理キーボードを使った行単位同期を完成させる。
