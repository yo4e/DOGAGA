# DOGAGA 競合調査

更新日: 2026-07-17

## 1. この調査の目的

DOGAGAは、既存の動画編集サービスを機能数で追いかけない。

この文書では、主要なブラウザ／初心者向け動画編集サービスを、DOGAGAが狙う次の用途から比較する。

- 楽曲を軸にしたMV／PV
- 歌詞動画、歌詞テロップ
- YouTube向け楽曲MV
- ショート動画
- Spotify Canvas
- 文字と字幕を多用する短尺動画

比較の目的は「どのサービスが一番強いか」を決めることではなく、DOGAGAが作るべき体験と、作らなくてよい機能を明確にすることである。

## 2. 調査上の注意

- 公式サイト、公式ヘルプ、公式製品ページを優先する
- 機能や料金、対応プラットフォームは変更される
- 同名機能でも、Web、デスクトップ、モバイルで提供範囲が違う場合がある
- マーケティングページだけで操作精度や使い勝手までは判断しない
- 重要機能は、実装前に同一素材を使った手動ベンチマークを行う

評価記号:

- `◎`: 製品の中心的な強み
- `○`: 実用的に提供されている
- `△`: 可能だが、用途専用ではない／制限がある
- `—`: 公式情報だけでは確認できない、または主眼ではない

## 3. 比較対象

- Canva
- CapCut
- Adobe Express
- VEED
- Microsoft Clipchamp
- Kapwing

これらは大きく三群に分かれる。

### デザイン起点

- Canva
- Adobe Express

テンプレート、デザイン素材、ブランド表現に強い。動画編集は「デザイン制作の一部」として提供される。

### 動画編集起点

- CapCut
- VEED
- Clipchamp

タイムライン、字幕、効果、SNS向け編集を幅広く扱う。

### クリエイター／共同制作起点

- Kapwing

クラウド編集、共有、AI、字幕、音楽動画用途を横断する。

DOGAGAは第四の位置として、**音楽と歌詞の時間軸を起点にした、ローカルファーストの小型編集機**を狙う。

## 5. 競合別分析

### 5.1 Canva

公式情報で確認できる特徴:

- ブラウザを含む簡単な動画編集
- テンプレート中心の開始導線
- トリム、結合、リサイズ、文字、フィルター
- ディゾルブを含むトランジション
- 自動字幕生成とスタイル編集
- Beat Syncによる音楽と映像の同期
- クラウド保存、共有、共同編集

強さ:

- 何を作るかを選べば、ほぼ迷わず編集画面へ入れる
- デザイン初心者でも、見栄えする成果物まで到達しやすい
- 比率変更、テンプレート、ブランド素材が一体化している

DOGAGAが学ぶ点:

- 起動直後に「MV」「歌詞動画」「Canvas」「Short」を選べる
- 専門用語より、完成用途を先に見せる
- 画面上の要素を直接選択して編集できる
- 自動処理を使っても、結果を手動で直せる

DOGAGAが差を作る点:

- 波形と歌詞一覧を同じ編集体験へ統合する
- タップ同期、一括オフセット、選択行以降の移動を標準機能にする
- ディゾルブやフェードの秒数を、初心者にも分かる形で調整できる
- 大容量素材を常時クラウドへ置かない

### 5.2 CapCut

公式情報で確認できる特徴:

- Web、デスクトップ、モバイルをまたぐ幅広い動画編集
- 自動字幕、文字アニメーション、効果、フィルター
- ビート同期やSNS向け制作
- SRT、ASS、LRC等の字幕／歌詞ファイル利用に関する案内
- モバイル版を中心としたAuto Lyrics

重要な更新:

- 2026年1月時点のCapCut公式ヘルプでは、Auto Lyricsはモバイルアプリで提供され、Web版とデスクトップ版では新規生成非対応とされている
- したがって「ブラウザで歌詞を快適に同期する」領域は、CapCutが完全に押さえているとは言えない

強さ:

- 効果、文字、テンプレート、AI機能の幅が非常に広い
- スマートフォンで短尺動画を作る体験が成熟している
- 流行の文字演出やSNS表現へすぐ到達できる

DOGAGAが学ぶ点:

- 歌詞動画専用入口を用意する
- 字幕ファイルの読み込み、手入力、自動生成を同じ場所へ集める
- 文字プリセットを選択時に即時プレビューする
- 音楽、ビート、文字演出を一つの制作体験として見せる

DOGAGAが差を作る点:

- Webで、既に持っている正しい歌詞を最短で同期できる
- AI認識の成否に依存しない
- 行単位の修正を速くし、全体ずれや途中以降のずれを一操作で直せる
- MV／Canvasに必要な機能だけを見せる

### 5.3 Adobe Express

公式情報で確認できる特徴:

- シーン単位の動画編集
- トリム、分割、複製、速度、音量
- シーン間トランジション
- テキスト、デザイン素材、テーマ
- 動画内音声から字幕を自動生成
- Transcriptパネルでの字幕本文確認と修正
- 字幕のフォント、色、背景、位置の調整
- SNS向けクリップ生成と比率指定

強さ:

- デザイン制作と動画制作の境界が薄い
- 字幕生成から修正、見た目の調整までが分かりやすい
- シーン単位なので、初心者が構造を理解しやすい

DOGAGAが学ぶ点:

- 初心者向け操作と詳細調整を同じ画面に詰め込まない
- 字幕本文の修正を、タイムラインだけに任せない
- 文字スタイルを一括変更できるようにする

DOGAGAが差を作る点:

- シーンではなく、楽曲の時間軸を中心にする
- 音楽波形、歌詞、ビート、フェードを第一級の編集対象にする
- 一曲分の長い歌詞を扱える一覧性を持つ

### 5.4 VEED

公式情報で確認できる特徴:

- ブラウザ上の動画編集
- 字幕自動生成、SRT／VTT読み込み
- 字幕本文、開始／終了時刻、タイムライン位置の編集
- 動的字幕、単語ハイライト、字幕アニメーション
- 字幕ファイル出力、焼き込み出力
- ドラッグ＆ドロップのトランジション
- VHS、グリッチ等の効果

強さ:

- 字幕本文とタイミングの修正機能が具体的
- 自動生成後の修正導線が強い
- 字幕スタイル、翻訳、出力まで一つのサービス内で完結する

DOGAGAが学ぶ点:

- 字幕一覧とタイムラインを双方向に選択できるようにする
- 開始と終了を数値でもドラッグでも直せるようにする
- 効果を技術名ではなく、見た目と用途で選ばせる

DOGAGAが差を作る点:

- 字幕ではなく、歌詞を持つ音楽制作者の操作に最適化する
- 「次の行頭まで表示」「選択行以降をずらす」など、歌詞同期特有の修正を持つ
- アップロード待ちを避け、素材を端末内で扱う

### 5.5 Microsoft Clipchamp

公式情報で確認できる特徴:

- ブラウザで動く一般向けタイムライン編集
- トリム、クロップ、比率変更、音声分離
- トランジションとクロスフェード
- アニメーション付きテキスト、タイトル、字幕
- 自動字幕と編集可能なトランスクリプト
- SRT出力
- 自動字幕ではAzure Cognitive Servicesを利用して音声を処理

強さ:

- 一般的なタイムライン編集の理解しやすさ
- Microsoft環境との連携
- 自動字幕とタイムスタンプ付きトランスクリプト

DOGAGAが学ぶ点:

- 基本タイムライン操作は独自性を狙わず、既知の操作を採用する
- 文字のフェード時間をスライダー等で簡単に調整できるようにする
- 外部処理が発生する機能では、送信先と目的を明示する

DOGAGAが差を作る点:

- 一般動画ではなく音楽動画へ用途を絞る
- 外部AIなしでも歌詞同期を完成できる
- 字幕生成より、正しい歌詞の配置と演出を優先する

### 5.6 Kapwing

公式情報で確認できる特徴:

- ブラウザ上の動画編集
- 音楽動画作成を明示した専用ページ
- 音声と映像の同期、音楽ビジュアライザー、歌詞動画
- YouTubeやSpotify Canvas用途への言及
- 自動字幕、手入力、SRT読み込み、タイミング調整
- クラウド保存、共有、コメント、共同制作
- ストック映像／音楽とAI機能

重要性:

Kapwingは、今回の比較対象の中でDOGAGAの想定用途へ最も近い訴求をしている。したがって「Spotify Canvasを作れる」というだけでは差別化にならない。

DOGAGAが学ぶ点:

- 「音楽動画を作る」という用途名を正面に置く
- 波形やビジュアライザーも、将来候補として検討する
- 同一プロジェクトからYouTube、Short、Canvasへ派生できる価値を見せる

DOGAGAが差を作る点:

- クラウド共同制作ではなく、個人制作者が端末内で素早く完成させる
- 歌詞本文を持つ人の同期と修正速度を中心にする
- 多機能なワークスペースではなく、制作完了までの手数を減らす

## 6. 代表タスク別の比較

### タスクA: 1分の楽曲PVを作る

競合で一般的な流れ:

1. テンプレートまたは空プロジェクトを選ぶ
2. 動画、画像、音源をアップロードする
3. クリップを配置する
4. 文字、効果、トランジションを追加する
5. 書き出す

DOGAGAで短縮する点:

- 最初に楽曲を置く
- 波形を基準に映像を配置する
- クリップ境界にディゾルブ候補をすぐ置ける
- 9:16、16:9等を制作開始時に固定する

### タスクB: 一曲分の歌詞動画を作る

競合で起きやすい問題:

- 自動認識が歌唱に弱い
- 正しい歌詞が手元にあっても、一行ずつ字幕化する必要がある
- 全体が少しずれた場合に、行ごとの修正が必要になる
- 途中からずれた場合の一括修正が弱い

DOGAGAの中心フロー:

1. 正しい歌詞を貼り付ける
2. 改行を行単位へ変換する
3. 再生しながらSpaceキーで行頭を同期する
4. Backspaceで直前の同期を戻す
5. 終了後、波形上で微調整する
6. 全体または選択行以降を一括でずらす
7. 文字スタイルをまとめて適用する

### タスクC: Spotify Canvasを作る

競合でも縦短尺動画は作れるが、Canvas固有の条件確認は制作者へ委ねられることが多い。

DOGAGAでは次を専用機能にする。

- 3〜8秒の尺制限
- 9:16固定
- ループ継ぎ目プレビュー
- Continuous／Hard Cut／Reboundの確認
- セーフエリア
- 点滅警告
- 書き出し前チェック

### タスクD: 字幕主体のShortを作る

競合は自動字幕と動的字幕に強い。

DOGAGAは初期段階で正面衝突しない。まず手入力、歌詞、SRT／VTT／LRCを快適にし、自動字幕はMVP後に追加する。

## 7. 市場上の空白

競合には既に、次の機能が揃っている。

- 自動字幕
- テンプレート
- AI生成
- ビート同期
- 多数の効果
- クラウド共同編集
- ストック素材

DOGAGAが狙うべき空白は、単一機能ではなく次の組み合わせである。

1. **正しい歌詞を持つ人向けの、確実で速い同期**
2. **ブラウザで完結する手動タップ同期**
3. **楽曲波形と歌詞一覧が一体化した編集体験**
4. **MV、短尺PV、Spotify Canvasへの用途特化**
5. **素材を安易にクラウドへ送らないローカルファースト**
6. **Canvaより時間軸を触れ、Premiereより圧倒的に迷わない**

## 8. 作らないことで差を守る

初期DOGAGAでは、次を競合しない。

- 大量のテンプレートとストック素材
- 生成AI動画プラットフォーム
- チーム共同編集
- 長編映画編集
- 本格カラーグレーディング
- 複雑なキーフレームアニメーション
- 多数のトランジション
- あらゆるコーデックへの万能対応

これらを足すと、DOGAGAの強みである「迷わず一曲分を完成させる」が崩れる。

## 9. 優先機能

### 優先度A: 独自価値

- 歌詞貼り付けと行分割
- Spaceキー／タップによる行頭同期
- 直前同期の取り消し
- 全行の一括オフセット
- 選択行以降の一括移動
- 次の行頭まで表示時間を自動設定
- 波形と歌詞一覧の連動
- Spotify Canvas専用プリセットとループ確認

### 優先度B: 完成度

- SRT／VTT／LRC読み書き
- ビート検出とマーカー
- クリップ境界のビートスナップ
- 文字アニメーションの少数精鋭プリセット
- 16:9／9:16／1:1への派生
- 文字スタイルの一括変更

### 優先度C: 後発機能

- 歌唱音声からの歌詞認識
- 単語単位の自動アラインメント
- 自動翻訳字幕
- クラウド同期
- 共同編集
- テンプレート共有

## 10. 手動ベンチマーク計画

公式ページだけでは、実際の手数、待ち時間、修正しやすさは分からない。Phase 0と並行して、次の同一素材テストを行う。

### 共通素材

- 60秒の権利確認済み楽曲
- 10本の短い映像／画像
- 30行の正しい歌詞
- 3〜8秒のCanvas候補区間

### 実施タスク

1. 60秒の縦PVを作る
2. 30行の歌詞を同期する
3. 全字幕を0.3秒後ろへ移動する
4. 15行目以降だけ0.2秒前へ移動する
5. ディゾルブを3か所追加する
6. 9:16と16:9を書き出す
7. 6秒のループ動画を作る

### 記録項目

- アカウント作成から編集開始までの時間
- 素材アップロード待ち
- 完成までの総時間
- クリック数／主要操作数
- 歌詞同期に要した時間
- 全体ずれ、途中ずれの修正手数
- 文字スタイル一括変更の可否
- 書き出し時間と制限
- 無料版の透かし、尺、解像度制限
- ブラウザ、OS、プラン
- 迷った箇所と誤操作

### DOGAGAの目標

- 30行の歌詞を10分以内に概ね同期できる
- 全体ずれを一操作で直せる
- 途中以降のずれを二操作以内で直せる
- 60秒PVを初見でも30分以内に完成できる
- Canvasの仕様違反をエクスポート前に検出できる

## 11. 現時点の結論

- 「簡単な動画編集」だけでは競合が多すぎる
- 「AI動画編集」も競争と運用コストが大きい
- Kapwingは音楽動画とSpotify Canvasまで訴求しており、用途名だけでは差別化できない
- CapCutのAuto LyricsがWebで完結しない現状は、DOGAGAの歌詞同期に明確な余地を作っている
- DOGAGAは、**自分の楽曲と正しい歌詞を持つ人が、端末内で公開用映像を短時間に作る道具**へ絞る
- 勝ち筋は機能数ではなく、歌詞同期と修正の速さ、保存の安心感、用途別書き出しである
