# DOGAGA 競合調査

更新日: 2026-07-17

この文書は、現時点の公式情報をもとにした初期調査である。機能や料金は変わるため、実装直前に再確認する。

## 1. 比較対象

- Canva
- CapCut
- Adobe Express
- VEED
- Microsoft Clipchamp

DOGAGAはこれらを丸ごと再現しない。狙う位置は、**Canvaの入りやすさと、CapCut / VEEDの音楽・字幕・効果機能の間**である。

## 2. 競合別メモ

### Canva

公式情報で確認できる主な特徴:

- ブラウザでの動画編集
- トリム、分割、リサイズ、速度変更
- トランジションとディゾルブ
- 音楽、文字、アニメーション
- 自動テロップ生成と編集
- ビート同期
- テンプレート中心の導線

DOGAGAが学ぶ点:

- 目的別テンプレートから始められる
- 専門用語を避け、画面上の要素を直接操作できる
- サイズ変更やSNS用途を先に見せる

DOGAGAが差を作る点:

- 楽曲波形と歌詞タイミングを中心にした編集
- タップ同期、一括オフセット、行単位／単語単位の調整
- ディゾルブやフェードの時間をより明確に制御
- ローカルファーストの保存方針

### CapCut

公式情報で確認できる主な特徴:

- ブラウザ版動画編集
- 自動字幕、Auto Lyrics、自動翻訳
- LRC / SRT / ASS等の字幕ファイル取り込み
- ビート同期
- 豊富なテンプレート、文字アニメーション、効果、フィルター
- SNS向け書き出し
- AIを使った短尺動画制作機能

DOGAGAが学ぶ点:

- 歌詞動画専用の入り口を用意する
- 字幕の生成、読み込み、手入力を同じ場所へ集める
- 文字プリセットとアニメーションを即時プレビューする
- ビートと文字を別機能にせず、一つの制作体験へまとめる

DOGAGAが差を作る点:

- 機能を増やしすぎず、歌詞同期の手作業を速くする
- AIが誤った場合でも、最初から直しやすい
- データ送信を必要最小限にし、ローカル処理を優先
- MVやCanvasに必要な項目だけを見せる

### Adobe Express

公式情報で確認できる主な特徴:

- シーン単位の動画編集
- トリム、分割、複製
- シーン間トランジション
- 文字、デザイン素材、テーマ
- 字幕自動生成、文字起こしの確認、字幕スタイル編集
- SNS向けサイズとテンプレート

DOGAGAが学ぶ点:

- シーンベースの簡単な操作
- 字幕生成後にトランスクリプトで修正できる導線
- 初心者向け機能と詳細編集を分離する

DOGAGAが差を作る点:

- シーンよりも楽曲時間軸を中心にする
- 歌詞一覧とタイムラインの双方向編集
- MV向けの波形、ビート、フェード、歌詞アニメーション

### VEED

公式情報で確認できる主な特徴:

- ブラウザでの動画編集
- 字幕の生成、SRT / VTT取り込み、修正、同期、装飾
- トランジションのドラッグ＆ドロップ
- VHS、グリッチ、フィルム風などの効果
- SNS向けのキャンバスサイズ

DOGAGAが学ぶ点:

- 字幕一覧で本文とタイミングを修正できる
- 効果を技術名ではなく見た目で選べる
- トランジションをクリップの境界へ置く操作

DOGAGAが差を作る点:

- 歌詞貼り付けから同期までを最短化
- 音楽用途に絞ったプリセット
- ローカル素材を基本とし、アップロード前提にしない

### Microsoft Clipchamp

公式情報で確認できる主な特徴:

- ブラウザで動く一般向けタイムライン編集
- トリム、回転、録画、音声録音などの基本機能
- 初心者向けと比較的細かな編集の両立

DOGAGAが学ぶ点:

- 一般的なタイムラインの分かりやすさ
- 録音や素材追加を編集画面から行える構造

DOGAGAが差を作る点:

- 一般動画ではなく、楽曲制作物へ用途を限定
- 歌詞、ビート、文字演出、Canvasプリセットを前面に出す

## 4. 市場上の空白

競合には、すでに自動字幕、テンプレート、トランジション、効果がある。DOGAGAが同じ機能を少しずつ持つだけでは弱い。

狙うべき空白は次の組み合わせである。

1. **歌詞本文を持っている人向けの、確実で速い同期**
2. **楽曲波形と文字が同じ編集体験の中にある**
3. **MV、短尺PV、Spotify Canvasへ用途を絞る**
4. **ブラウザだが、素材を安易にクラウドへ送らない**
5. **Canvaより時間軸を触れ、Premiereより圧倒的に迷わない**

## 5. 差別化機能候補

### 優先度A

- 歌詞貼り付け→自動行分割
- スペースキー／タップによる行頭同期
- 全歌詞の一括オフセット
- 選択行以降の一括ずらし
- 行の長さを次の行頭まで自動調整
- 波形ズームと歌詞一覧の連動
- Spotify Canvas専用プリセットとループ確認

### 優先度B

- ビート検出とマーカー
- 映像カットをビートへスナップ
- 単語単位のカラオケ表示
- 文字アニメーションの少数精鋭プリセット
- 同一プロジェクトから16:9 / 9:16 / 1:1を派生

### 優先度C

- 歌唱音声からの歌詞認識
- 自動翻訳字幕
- テンプレート共有
- クラウド同期と共同編集

## 6. 競合調査からの結論

- 「簡単な動画編集」だけでは競合が多すぎる。
- 「AI動画編集」も競争が激しく、外部API費用とデータ問題が増える。
- DOGAGAは、**自分の楽曲と歌詞を持つ人が、公開用の映像を短時間で作る道具**に絞る。
- その結果として、MV、PV、ショート、Spotify Canvasが同じ編集基盤から作れるようにする。
