# DOGAGA（どーがが）

ブラウザで動く、シンプルな動画編集ツールのプロジェクト。

Premiere Proのような総合編集ソフトを再現するのではなく、日常的によく使う編集機能だけを、軽く・速く・迷わず使える形に絞る。

このREADMEは、プロジェクトを次に開いた人間やAIが、すぐ文脈を復元できるようにするための起点でもある。

## 現在の構想

- 名称：DOGAGA
- 読み：どーがが
- 形態：ブラウザで動くWebアプリ
- 当面の公開先：よろずコム配下のサブドメイン
- 開発方針：競合調査と技術検証を行いながら、まずプロトタイプを作って育てる
- 想定利用者：まずは山田佳江本人。実用性が出た段階で一般公開も検討する

## 目指すもの

「動画を切る・つなぐ・文字を入れる・少し加工する・書き出す」を、複雑な設定や巨大な機能群に邪魔されず、ブラウザだけで完結できる編集ツール。

万能なプロ向け編集ソフトではなく、必要十分な小型編集機を目指す。

## MVP候補

最初のプロトタイプでは、以下を優先候補とする。

- 動画ファイルの読み込み
- タイムラインへの配置
- クリップの分割、トリミング、並べ替え
- 複数クリップの連結
- ディゾルブ
- テキスト／字幕の追加
- 音量調整、フェード
- よく使う簡単な映像効果
  - ノイズ／グレイン
  - モノクロ
  - 明るさ、コントラスト、彩度などの基本補正
- 画面比率と解像度の指定
- MP4などへの書き出し
- プロジェクトの保存と再開

## 技術上の仮説

現時点では、以下の技術を候補として考えている。まだ確定ではない。

- WebCodecs：動画・音声のデコード／エンコード
- Canvas / WebGL：プレビュー、文字、エフェクト、合成
- ffmpeg.wasm：変換や書き出しの補助
- OPFS / IndexedDB：サムネイル、波形、プロキシなどの作業用データ
- JSON形式の独自プロジェクトファイル：編集内容の保存

まずはMac＋Chromeを主要対象にして、ブラウザ間差異を後から検討するのが現実的。

## 保存方針の仮案

動画本体をサーバーへ常時アップロードする方式ではなく、ローカルファーストを基本案とする。

- 元動画：ユーザーの端末や外付けSSDなどに置く
- プロジェクト：編集指示をJSON等で保存する
- 作業用キャッシュ：ブラウザ内ストレージに保存する
- 完成動画：ユーザーが指定した場所へ書き出す

ブラウザ内ストレージは消える可能性があるため、唯一の保存先にはせず、プロジェクトファイルの書き出し・読み込みを可能にする。

DOGAGAは現時点のワーキングネーム。

今後、以下を調査する。

- DOGAGA / どーがが の完全一致・類似名称
- 動画編集アプリ、動画配信サービス、ソフトウェア会社との競合
- 商標の登録状況と類似群
- 利用可能なドメイン／サブドメイン
- 主要なブラウザ動画編集サービスの機能、価格、弱点
- DOGAGAが選ばれる理由を作れる余白

名称や商標については、通常検索だけで判断せず、公開規模が大きくなる前に正式な確認を行う。

## 開発の進め方

1. 競合と名称を調査する
2. 最小機能を決める
3. 動画の読み込み・プレビュー・カット・連結だけの技術試作を作る
4. タイムライン操作の感触を検証する
5. ディゾルブ、文字、音声、簡易エフェクトを追加する
6. 保存と書き出しを安定させる
7. よろずコムのサブドメインで試験運用する
8. 実際の制作で使いながら改修する

## 重要な設計思想

- Premiere Proの縮小コピーにはしない
- 機能数より、操作の速さと分かりやすさを優先する
- 山田佳江が実際に使う操作を中心に設計する
- ローカルファーストを基本にし、大容量動画を安易にクラウドへ送らない
- プロトタイプを早く作り、実利用から仕様を育てる
- AI／Codexと協働しやすいよう、判断理由と仕様を文書に残す
